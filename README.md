# SportTrack

Готовый сайт на React с нуля. Проект запускается самостоятельно — исходный React-проект или репозиторий не требуется.

## Требования
- Node.js 18 или новее
- npm

## Запуск
1. Распакуйте архив.
2. Откройте папку `SportTrack` в VS Code.
3. Откройте терминал в этой папке.
4. Выполните:

```bash
npm install
npm run dev
```

5. Откройте адрес, который покажет Vite (обычно http://localhost:5173).

## Сборка
```bash
npm run build
npm run preview
```

## Страницы
- Главная панель (Dashboard)
- История достижений: поиск, фильтр, добавление и удаление
- Подробная карточка достижения
- Проверка достижений тренером: подтверждение и отклонение
- Добавление, изменение и удаление записей, цель на дашборде, уведомления
- Формирование отчётов с предпросмотром

## Типографика и микротексты (ЛР №3)
- Шрифты: Inter (основной, 400–700) и Source Serif 4 (акцентные блоки, 400 и 600). Подключаются через пакеты `@fontsource/*` в `src/main.jsx` (WOFF2, `font-display: swap`, файлы раздаются самим приложением)
- Шкала 16 px × 1,2: 12 / 14 / 16 / 19 / 22 / 26 / 32 / 40 px, размеры заданы в `rem`; заголовки H1–H3 адаптивны через `clamp()`
- Токены типографики и цвета — в начале `src/sporttrack/styles/sporttrack.scss`
- Все тексты кнопок, сообщений и мотивационные фразы — в `src/sporttrack/content/microtexts.js` (таблицы 7–9 отчёта)
- Контраст пар «текст — фон» не ниже WCAG 2.2 AA; на залитых кнопках используется тёмный текст `#0A1430`

## Фирменные цвета
- Navy (фон): `#0A1430`
- Blue: `#0297DE`
- Coral: `#FC734D`

Данные демонстрационные и хранятся в состоянии React. Для постоянного хранения и реальной авторизации потребуется backend/API.
